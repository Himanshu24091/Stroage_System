How to Use StealthVault

Master file uploading, cloud folders, in-browser previews & stealth streaming

🛡️
100% Stealth Cloud Storage

Files are securely stored in Google Drive while streaming directly through an encrypted proxy. Your ISP and company network only see vault traffic.

1

Upload Your Files

Drag & drop anywhere or click the upload zone. Big files up to hundreds of MBs and GBs are supported via chunked resumable upload.

2

Organize in Color Folders

Create custom color-coded folders (Blue, Emerald, Purple, Amber, etc.). Move files between folders or download whole folders as ZIP.

3

Instant In-Browser Preview

Click any thumbnail or file name to view PDFs, stream high-res videos, listen to audio, or inspect code and ZIP archives instantly.

4

Batch Actions & Shortcuts

Use checkboxes to select multiple files to batch move, batch download in a ZIP, or batch delete with the floating action bar.

Chunked Resumable Upload (No File Size Limits)

Large files (like software, 4K videos, ISOs, and raw datasets) are automatically split into 8MB binary chunks. If your network fluctuates, failed chunks retry automatically without restarting from zero!

Direct Folder Upload

When you open any folder, files you upload will automatically go straight into that folder! You can also change the target folder anytime using the folder selector above the upload box.

Google Drive Link Importer

Have a public Google Drive sharing link? Paste it in the "Drive Link Importer" tab to stream or proxy the file through your vault without downloading it first to your device.

Creating & Customizing Folders

Click the + New Folder button in the top action bar. You can choose a custom color accent (Blue, Purple, Emerald, Amber, Rose, Indigo) to make your workspace instantly identifiable.

1-Click Folder ZIP Download

Need to download an entire folder? Just click the three dots (⋮) on any folder card and choose 📦 Download ZIP. StealthVault will dynamically stream all files inside the folder compressed as a single ZIP download.

Folder Navigation & Breadcrumbs

Click on any folder card to step inside. The interactive breadcrumb trail at the top lets you navigate back to parent folders or the root Vault with one click.

In-Browser ZIP Archive Explorer

Click on any .zip file in your vault! StealthVault will parse the archive headers and let you inspect all files inside without downloading the full archive. You can even filter with live search and download individual files directly!

PDFs, Videos & High-Res Media

Click to open PDFs with native page navigation and zooming. Stream MP4/WebM videos with speed controls (0.5x to 2x), listen to audio tracks, and inspect high-resolution photography without leaves your browser.

Formatted Code & Markdown Viewer

Native dark-mode syntax highlighted viewer for Python, JavaScript, CSS, HTML, JSON, and rendered Markdown documents.

Floating Batch Action Dock

Select files using their checkboxes (or click Select All). A floating action bar docks at the bottom with options to Download Batch ZIP, Move to Folder, or Move to Trash simultaneously.

⭐ Starred Favorites

Click the star icon (☆) on any file or folder card. Switch to the Starred view tab anytime in the top bar to quickly access your priority items.

Recycle Bin (Trash) with Safe Restore

Deleted files and folders are moved to the Trash tab rather than being permanently destroyed. You can restore them back to your vault at any time, or permanently delete them when you're sure.

💡 You can reopen this instruction guide anytime by clicking Instructions in the top navbar.
